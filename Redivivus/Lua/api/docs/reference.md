# Redivivus mod API reference

Generated by `Redivivus/Lua/tools/src/gen.ts` from the declarations the compiler emitted for the core's
public modules (`Redivivus/Lua/core/redivivus/*.ts`). Do not edit.

Every module is imported: `import { log } from "redivivus:shared"` in TypeScript, `local shared =
require("redivivus:shared")` in Lua. A mod's control entry `main` exports `server(game)` and/or
`client(client)`; everything a mod does in a game it registers through the object it receives.

|Module|Resolves in|Needs|
|-|-|-|
|`redivivus:automation`|client|a driver script|
|`redivivus:client`|data, server, client|-|
|`redivivus:data`|data, server, client|-|
|`redivivus:enums`|data, server, client|-|
|`redivivus:lualib`|data, server, client|-|
|`redivivus:manager`|data, server, client|-|
|`redivivus:mods`|data, server, client|-|
|`redivivus:server`|data, server, client|-|
|`redivivus:shared`|data, server, client|-|
|`redivivus:test`|server|the test runner|
|`redivivus:ui`|data, server, client|-|

## redivivus:automation

### `isDriver: unknown`

True: the importer is a driver script.

## redivivus:client

- `export { Event } from "./enums";`

### `interface ClientEvents`

The events the client raises, keyed by Event.

- `[Event.Tick]: EventBase;` - Every client frame tick.
- `[Event.Draw]: EventBase;` - When the UI is drawn.

### `interface ClientChannel<R extends Messages, E extends Messages>`

A channel as a client has it, for one game.

- `readonly name: string;`
- `readonly call: { readonly [K in keyof R]: (this: void, ...args: MessageArgs<R[K]>) => void; };` - Send a request to the server.
- `readonly on: { readonly [K in keyof E]: (this: void, handler: (this: void, ...args: MessageArgs<E[K]>) => void) => void; };` - Handle an event the server sends.

### `interface Client`

One game this client is in, as one mod sees it. Everything registered through it ends with the game.

- `readonly gameId: number;` - The game's id on this client.
- `readonly tick: number;` - The current client tick.
- `on<K extends keyof ClientEvents>(this: void, event: K, handler: ((this: void, e: ClientEvents[K]) => void) | undefined): void;` - Subscribe to an event; undefined unsubscribes. One handler per event per mod.
- `startScript(this: void, body: (this: void) => Script<void>, owner?: Handle): ScriptTask;` - Start a script for this game, resumed each client tick it is due.
- `waitEvent<K extends keyof ClientEvents>(this: void, event: K): Script<ClientEvents[K]>;` - Wait for an event of this game inside one of its scripts. The outcome is the payload.
- `channel<R extends Messages, E extends Messages>(this: void, declaration: ChannelDeclaration<R, E>): ClientChannel<R, E>;` - Open a channel of this mod for this game.

### `type ClientEntry = (this: void, client: Client) => void;`

The type of a mod's `client` export.

### `interface MenuScreen`

A full screen of the main menu, made with menu.addScreen. While it is open it is the whole
menu: it draws every frame through redivivus:ui and gets the mouse and the keyboard; closing it
returns to the main menu. Escape closes it when nothing in it took the key.

- `open(this: void): void;` - Open the screen (from a main menu button, or from another screen of the same mod).
- `close(this: void): void;` - Close it and return to the main menu.
- `isOpen(this: void): boolean;`

### `interface Menu`

The main menu, as one mod sees it: what a mod's `menu` export receives, once, in the client
state, when the main menu first comes up. What a mod adds stays for the whole session.

- `addButton(this: void, label: string, onClick: (this: void) => void): void;` - Add a button to the main menu, below the stock ones, labelled in the game's button font. The menu has room for two; a mod's button that does not fit is left out and logged.
- `addScreen(this: void, view: (this: void, screen: MenuScreen) => Child): MenuScreen;` - A full screen. `view` builds it (a redivivus:ui component) each time it opens, and gets the screen so it can close itself.

### `type MenuEntry = (this: void, menu: Menu) => void;`

The type of a mod's `menu` export.

## redivivus:data

### `interface Prototype`

A prototype: a row of a data table.

- `readonly type: string;`
- `readonly name: string;`
- `[field: string]: unknown;`

### `interface Data`

The data stage's shared table.

- `readonly raw: { [type: string]: { [name: string]: Prototype; }; };` - Every prototype by type and name.
- `extend(this: void, prototypes: Prototype[]): void;` - Add prototypes; only in the data stage.

### `data: Data`

The data stage's shared table. Every mod sees the same one.

## redivivus:enums

- `export * from "./engine-enums";`

### `enum Event`

Every event. The value is the event's name on the wire, in payloads (`e.name`) and in logs;
which events a side raises is its events map (ServerEvents, ClientEvents).

- `Tick = "tick"` - A game tick (server) or a client frame tick.
- `Draw = "draw"` - The client draws the UI.

### `enum Side`

The states a mod runs in, each a Lua state of its own.

- `Data = 1`
- `Server = 2`
- `Client = 4`

### `enum Alignment`

Whose side a unit is on (the engine's alignment stat).

- `Evil = 0`
- `Neutral = 1`
- `Good = 2`

### `enum StateMask`

The masks of states.txt: a unit has one when any of its states has that column set.

- `Udead = 0` - Undead-like: frozen, revived, a corpse not drawn or not selectable, shattered...
- `Hide = 1` - Hidden.
- `Active = 2`
- `Aura = 3`
- `RemHit = 4`
- `Restrict = 5`
- `Life = 6`
- `Shatter = 7`

### `enum MinionOrder`

An order a group's leader gives its minions (the command their AIs read next).

- `Attack = 1` - Go for the target and attack it, without fleeing.

### `enum Outcome`

How an action or a wait ended.

- `Done = 0` - It did what it set out to.
- `Interrupted = 1` - Something intervened (the target died, the unit was stunned).
- `Blocked = 2` - It could not start or go on (no path).
- `Timeout = 3` - Its time ran out first.

### `enum MonsterAiId`

The monster AIs: the stock rows of monai.txt (the MonStats "AI" column), in the engine's order.
Registry ids of `game.registry.ai`; the value is the row's name.

148 members: `None = "None"`, `Idle = "Idle"`, `Skeleton = "Skeleton"`, `Zombie = "Zombie"`, `Bighead = "Bighead"`, `BloodHawk = "BloodHawk"`, `Fallen = "Fallen"`, `Brute = "Brute"`, `SandRaider = "SandRaider"`, `Wraith = "Wraith"`, `CorruptRogue = "CorruptRogue"`, `Baboon = "Baboon"`, ...

### `enum PointKind`

Which grid a point is on. Units and collision use subtiles; rooms and levels are laid out in tiles of 5 by 5 subtiles.

- `Subtile = "subtile"`
- `Tile = "tile"`

### `enum SettingType`

The value type of a mod setting.

- `Bool = "bool"`
- `Int = "int"`
- `Number = "number"`
- `String = "string"`
- `Choice = "choice"`

### `enum SettingScope`

Who reads a mod setting, and when it can change.

- `Startup = "startup"` - Every state, the data stage included; fixed until the game restarts.
- `Game = "game"` - The server; fixed for a game.
- `Player = "player"` - The client: the local player's own value.

### `enum ModState`

How an installed mod stands this session (redivivus:mods).

- `Enabled = "enabled"` - It is loaded.
- `Disabled = "disabled"` - The player turned it off.
- `Faulted = "faulted"` - It failed while loading (an error, or it ran out of time or memory); `error` says why.
- `MissingDependency = "missingDependency"` - A dependency is missing, turned off, the wrong version, or an incompatible mod is on; `error` says which.

### `enum DependencyState`

How one dependency of an installed mod is met (redivivus:mods).

- `Ok = "ok"`
- `Missing = "missing"`
- `Version = "version"` - Installed, but not a version the constraint accepts.
- `Optional = "optional"` - An optional dependency (installed or not).
- `Incompatible = "incompatible"` - "! other": installed although it may not be.

### `enum ExampleId`

The ids of the example registry. A mod adds its own by augmenting this enum
(`declare module "redivivus:enums" { const enum ExampleId { X = "my-mod:x" } }`).

- `Greet = "redivivus:greet"` - "hello, <name>".

### `enum SizeMode`

A size mode on one axis; a number of pixels is the third kind of size.

- `Content = "content"` - As large as the content (the default).
- `Fill = "fill"` - A share of the free space, by `flex`.

### `enum Align`

Where a child sits on the cross axis of its row or column.

- `Start = "start"`
- `Center = "center"`
- `End = "end"`
- `Stretch = "stretch"`

### `enum Justify`

How the children of a row or column share its main axis.

- `Start = "start"`
- `Center = "center"`
- `End = "end"`
- `Between = "between"` - The free space between the children.

### `enum TextAlign`

Horizontal alignment of text inside its box.

- `Left = "left"`
- `Center = "center"`
- `Right = "right"`

### `enum Direction`

The main axis of a frame or flow.

- `Row = "row"`
- `Column = "column"`

### `enum BoxStyle`

The theme's chrome behind a container.

- `None = "none"`
- `Panel = "panel"`
- `Dialog = "dialog"`
- `Inset = "inset"`
- `Code = "code"`
- `Quote = "quote"`
- `Screen = "screen"` - The full-screen backdrop of a menu screen.

### `enum ButtonVariant`

The theme's button art.

- `Wide = "wide"`
- `Medium = "medium"`
- `Narrow = "narrow"`
- `Short = "short"`
- `Cancel = "cancel"`
- `Small = "small"` - A text button in the smallest of the theme's fixed button art its label fits (never stretched).

### `enum FontRole`

- `Small = "small"`

The text colours a theme names; a number is a colour code of the game's own.

- `Link = "link"`
- `Code = "code"`
- `Heading = "heading"`
- `Ok = "ok"`
- `Warning = "warning"`

### `enum BlendMode`

How an image or rectangle is blended. The kit's numbers, not the engine's DrawMode.

- `Normal = 0` - Opaque; palette index 0 of a sprite is transparent.
- `Trans25 = 1` - 25% opaque: the engine's light transparency.
- `Trans50 = 2` - 50% opaque.
- `Trans75 = 3` - 75% opaque.

- `Additive = 5` - Adds the image to what is under it (the game's light).

## redivivus:manager

### `function setEnabled(changes: { readonly [name: string]: boolean; }): void;`

Set mods on or off in the player's mod list (mods/mod-list.json), keyed by name; the others keep
their entries. Takes effect when the game restarts. Raises when the file cannot be written.

### `function restart(): void;`

Restart the game with the mod list as it is now: this process quits as the main menu's Exit does
and the same executable starts again with the same command line. Raises when the game cannot
restart itself.

## redivivus:mods

- `export { DependencyState, ModState } from "./enums";`

### `interface InstalledDependency`

One dependency of an installed mod.

- `readonly spec: string;` - As written in info.json: "redivivus >= 0.1", "? other", "! enemy".
- `readonly name: string;`
- `readonly state: DependencyState;`
- `readonly installed: string;` - The installed version, or "" when it is not installed.

### `interface InstalledMod`

An installed mod.

- `readonly name: string;`
- `readonly title: string;` - The title, or the name when info.json has none.
- `readonly version: string;`
- `readonly author: string;`
- `readonly licence: string;`
- `readonly enabled: boolean;` - On in the player's mod list (it may still not load: see state).
- `readonly state: ModState;`
- `readonly error: string;` - Why it is not loaded, or "".
- `readonly dependencies: readonly InstalledDependency[];`

### `interface InstalledSetting`

A setting an installed mod declared, with the value in effect.

- `readonly mod: string;`
- `readonly name: string;`
- `readonly title: string;` - The declared title, or the name.
- `readonly type: SettingType;`
- `readonly scope: SettingScope;`
- `readonly value: boolean | number | string;`

### `function installedMods(): InstalledMod[];`

Every installed mod: the ones that load in load order, then the rest by name. Fresh tables.

### `function readme(mod: string): string;`

An installed mod's README.md (Markdown, at most 256 KiB), or "" when it has none.

### `function changelog(mod: string): string;`

An installed mod's CHANGELOG.md, or "".

### `function installedSettings(): InstalledSetting[];`

Every setting the installed mods declared, with its value. Fresh tables.

## redivivus:server

- `export { AiTargeting, Alignment, Event, MinionOrder, MonsterAiId, MonsterId, MonsterMode, Outcome, PointKind, SkillId, StatId, StateId, StateMask, UnitType } from "./enums";`

### `interface ServerEvents`

The events a game raises, keyed by Event. A mod subscribes with game.on.

- `[Event.Tick]: EventBase;` - Every game tick, before the scripts that are due resume.

### `interface ExampleRegistry`

The example registry: shows keyed entries, a native implementation at the bottom of an entry's
chain, and ids added by mods (augment ExampleId in redivivus:enums and this interface here).

- `[ExampleId.Greet]: (this: void, name: string) => string;` - Greets: "hello, <name>".

### `type ExampleSlot = (this: void, value: number) => number;`

The example single-slot registry: doubles a number.

### `interface ServerRegistries`

The behaviour registries of a game.

- `readonly example: KeyedRegistry<ExampleRegistry>;`
- `readonly exampleSlot: SlotRegistry<ExampleSlot>;`

### `interface ServerChannel<R extends Messages, E extends Messages>`

A channel as the server has it, for one game.

- `readonly name: string;`
- `implement(this: void, handlers: { [K in keyof R]: (this: void, peer: number, ...args: MessageArgs<R[K]>) => void; }): void;` - Handle the requests. Each handler gets the sending client's peer id first.
- `readonly emit: { readonly [K in keyof E]: (this: void, peer: number, ...args: MessageArgs<E[K]>) => void; };` - Send an event to one client, or to every client with peer 0.

A point on the subtile grid: where units stand, what collision and distances use.

- `readonly kind: PointKind.Subtile;`
- `readonly x: integer;`
- `readonly y: integer;`

### `interface Tile`

A point on the tile grid (5 by 5 subtiles): how rooms and levels are laid out.

- `readonly kind: PointKind.Tile;`
- `readonly x: integer;`
- `readonly y: integer;`

### `interface SubtileRect`

A rectangle of subtiles.

- `readonly x: integer;`
- `readonly y: integer;`
- `readonly width: integer;`
- `readonly height: integer;`

### `function subtile(x: integer, y: integer): Subtile;`

A subtile point.

### `function tile(x: integer, y: integer): Tile;`

A tile point.

### `function toTile(p: Subtile): Tile;`

The tile a subtile lies in.

### `function toSubtile(p: Tile): Subtile;`

The subtile at a tile's top corner.

### `interface Level`

A level of the game (an area: Blood Moor, a town). A handle: it exists while the level is
allocated in this game, which happens when a player first comes near it, never because a mod
asked.

- `readonly id: LevelId;`
- `readonly name: string;` - The level's name, localised.
- `readonly act: Act;`
- `readonly isTown: boolean;`
- `readonly generated: boolean;` - Whether its rooms are generated.
- `readonly bounds: SubtileRect | undefined;` - Its extent when generated.
- `rooms(): LuaIterable<Room>;` - Its active rooms (the ones near a player).
- `units(type?: UnitType): LuaIterable<AnyUnit>;` - The units in its active rooms, optionally of one type. A snapshot: units gone since are skipped.
- `monsters(): LuaIterable<Monster>;`
- `players(): LuaIterable<Player>;`

### `interface Room`

A room of a level, active while a player is near. A handle that names the room by its place, so it
is valid again when the room is loaded again.

- `readonly bounds: SubtileRect;`
- `readonly level: Level;`
- `neighbours(): LuaIterable<Room>;` - The active rooms next to it.
- `units(type?: UnitType): LuaIterable<AnyUnit>;`
- `monsters(): LuaIterable<Monster>;`
- `players(): LuaIterable<Player>;`

### `interface Unit`

A unit: a player, a monster, an object, a missile, an item. A handle: it names the unit by type
and id and is looked up on every use. It is not valid once the unit is gone, while its room is
unloaded (a monster comes back with its room, under the same id), and for a monster while it is
dead. Any member but `valid`, `id` and `type` then raises an error.

- `readonly id: integer;` - The unit's id (its guid; ids are per type).
- `readonly type: UnitType;`
- `readonly classId: integer;` - The row of its class table (MonStats for a monster, the class for a player).
- `readonly game: Game;`
- `readonly position: Subtile;`
- `readonly room: Room | undefined;`
- `readonly level: Level | undefined;`
- `readonly act: Act;`
- `readonly mode: integer;` - The mode: what it is doing. Monsters and players narrow it.
- `readonly owner: AnyUnit | undefined;`
- `distanceTo(other: Unit | Subtile): number;` - Straight-line distance in subtiles.
- `nearby(radius: number, type?: UnitType): LuaIterable<AnyUnit>;` - Units within radius subtiles of this one (itself excluded), optionally of one type.
- `getStat(stat: StatId, layer?: integer): number;` - A stat's value with every modifier (life, mana and stamina in whole points).
- `getBaseStat(stat: StatId, layer?: integer): number;` - A stat's base value, before modifiers.
- `setStat(stat: StatId, value: number, layer?: integer): void;` - Set a stat's base value through the stat list; gold goes through the gold rules elsewhere.
- `addStat(stat: StatId, delta: number, layer?: integer): void;` - Add to a stat's base value.
- `hasState(state: StateId): boolean;`
- `addState(state: StateId, frames?: integer): boolean;` - Put the unit in a state for frames (0: until removed). False when the engine refused.
- `removeState(state: StateId): void;`

### `interface Monster`

A monster (and NPCs, which are monsters too).

- `readonly type: UnitType.Monster;`
- `readonly classId: MonsterId;`
- `readonly mode: MonsterMode;`
- `readonly champion: boolean;`
- `readonly unique: boolean;`
- `readonly superUnique: boolean;`
- `readonly minion: boolean;`
- `readonly boss: boolean;`
- `life: number;` - Life in whole points; setting it to 0 or less is refused, use kill.
- `readonly maxLife: number;`
- `readonly target: AnyUnit | Corpse | undefined;` - The target of what it is doing now (a corpse while it raises one).
- `kill(killer?: Unit): void;` - Kill it as a script does: death, drops, quest hooks. A killer gets the experience.
- `readonly data: MonsterData;` - Its MonStats row, as the game's difficulty reads it.
- `readonly leader: Monster | undefined;` - The leader of its group as the AI sees it (itself when it leads one), when there is one.
- `readonly alignment: Alignment;`
- `random(max: integer): integer;` - A roll of the monster's own seed, modulo max (1 or more): the stream the stock AIs roll, so a script that rolls where a stock AI rolls makes the same decisions.
- `hasStateMask(mask: StateMask): boolean;` - Whether a state of one of the states.txt masks is on it.
- `aiDistanceTo(other: Unit | Corpse): integer;` - The distance as the AI measures it: the larger axis plus half the smaller, less its size.
- `minions(): LuaIterable<Monster>;` - The living monsters of the group it leads, in the engine's order.
- `minionCorpses(): LuaIterable<Corpse>;` - The corpses of the group it leads, in the engine's order.
- `corpsesNear(radius: number): LuaIterable<Corpse>;` - The monster corpses in the rooms around it within radius subtiles, in the order the engine's own scans meet them (room by room of its adjacent rooms).
- `findTarget(): { readonly target: AnyUnit; readonly distance: integer; } | undefined;` - The target the engine's AI would pick now (an AI's FindTargetAndDistance), with its AI distance.
- `canCast(skill: SkillId, at: Unit | Corpse): boolean;` - Whether the skill can be cast at the unit or corpse now (its target and placement checks).
- `orderMinions(order: MinionOrder): void;` - Give each monster of the group it is in an order (what the group's AIs read next).
- `readonly lifePercent: integer;` - Life in percent of its maximum, as the engine rounds it down (the life bands the AIs test).
- `collidesWith(other: Unit, mask: integer): boolean;` - Whether a collision of the mask (the engine's collision bits) lies between it and the unit.
- `scanTargets(): TargetScan;` - The engine's target scan as Mephisto's AI makes it: what it could attack around it, in the scan's order.
- `setPathOverrides(pathType: integer, velocity: integer, steps: integer): void;` - How its next move paths (the engine's AITACTICS_SetPathOverrides): path type (1 is taken as 7), velocity change, steps. Lasts until the next override; only inside its own AI script.
- `idle(frames?: integer): Script<Outcome>;` - Stand for frames (default: its AI delay), then think again.
- `walkTo(to: Subtile): Script<Outcome>;` - Walk to a point. Blocked when no path could be started or it stopped short.
- `runTo(to: Subtile): Script<Outcome>;` - Run to a point (walks when it cannot run).
- `walkToward(target: Unit, moveFlags?: integer): Script<Outcome>;` - Walk toward a unit (moveFlags: the engine's StartMonsterMove flags). Interrupted when the unit is gone or dead.
- `runToward(target: Unit): Script<Outcome>;`
- `attack(target: Unit, secondary?: boolean): Script<Outcome>;` - Attack (Attack1, or Attack2 with secondary).
- `castSkill(skill: SkillId, at: Unit | Corpse | Subtile, mode?: MonsterMode): Script<Outcome>;` - Cast a skill in a mode (default Cast; a MonStats SkMode column gives a skill's own).
- `castSequence(skill: SkillId, at: Unit | Corpse | Subtile): Script<Outcome>;` - Cast a sequence skill (mode Sequence: the animation the skill's sequence table plays), as a resurrect.
- `circleToward(target: Unit, steps: integer, flank?: boolean): Script<Outcome>;` - Close in on a unit along a curve, clockwise or not by a roll of its seed, steps long (flank: the engine's other direction flags, as Mephisto closes in).
- `walkPast(target: Unit, offset: integer, force?: boolean): Script<Outcome>;` - Walk toward a unit and offset subtiles on past it, along the line from here (force: even when close).
- `wanderAround(target: Unit, radius: integer): Script<Outcome>;` - Walk to a random spot within radius of a unit.
- `walkToDistance(target: Unit, maxStep: integer, distance: integer): Script<Outcome>;` - Drop its pending think and walk to distance subtiles from a unit, at most maxStep at a time.
- `wander(radius: integer): Script<Outcome>;` - Walk to a random spot within radius.
- `flee(from: Unit, distance: integer): Script<Outcome>;` - Run away from a unit for distance subtiles.

### `interface Player`

### `interface Corpse`

A monster's body: the monster while it lies dead. A handle of its own, named by the monster's id:
valid while the monster is dead and its room loaded, and not valid once it is alive again (its
Monster handle is then valid) or gone.

- `readonly id: integer;` - The monster's id (its Monster handle has the same).
- `readonly classId: MonsterId;`
- `readonly baseId: MonsterId;` - The base class of its MonStats row (fallen1 for every Fallen).
- `readonly position: Subtile;`
- `readonly mode: MonsterMode;`
- `readonly alignment: Alignment;`
- `readonly targetable: boolean;` - Whether it can be selected and targeted (a corpse used up by a skill is not).
- `readonly champion: boolean;`
- `readonly unique: boolean;`
- `readonly leader: Monster | undefined;` - The leader of the group it was in, when there is one.
- `hasStateMask(mask: StateMask): boolean;`
- `distanceTo(other: Unit | Corpse | Subtile): number;` - Straight-line distance in subtiles.

### `type AnyUnit = Player | Monster | (Unit & { readonly type: Exclude<UnitType, UnitType.Player | UnitType.Monster>; });`

Any unit a query gives: narrow it by `type`.

### `interface TargetScan`

What a target scan found: the units it could attack within a squared distance of 1024 (about 32
subtiles). Distances are squared subtiles.

- `readonly nearest: AnyUnit | undefined;`
- `readonly nearestDistance: integer;`
- `readonly weakest: AnyUnit | undefined;` - The one with the least life (whole points), the first of equals in the scan's order.
- `readonly weakestLife: integer;`
- `readonly nearestWhenPlayer: AnyUnit | undefined;` - The nearest, kept only when the scanning unit is a player: never for a monster (the engine tests the scanner).

### `type AiScript = (this: void, monster: Monster, think: Think) => Script<void>;`

A monster's AI as a script: it runs once per monster, from the top, when the monster gets the AI
(spawned, its room loaded, revived, a curse wears off: whenever the engine attaches an AI) and
ends when the monster dies or is gone. A bare `yield` waits one think; `yield* monster.walkTo(p)`
runs an action and gives its Outcome. When it returns it starts over at the next think.

### `type AiWrapper = (this: void, next: (this: void) => void, monster: Monster, think: Think) => void;`

A wrapper around one think of an AI: next() runs one think of what is below (the stock AI, or a
script a mod registered, or a lower wrapper). A wrapper that does not call next and starts no
action leaves the monster idle for its AI delay.

### `interface Game`

One game, as one mod sees it. Everything registered through it is dropped when the game ends.

- `readonly id: number;` - The game's id in this process.
- `readonly tick: number;` - The current tick.
- `storage<T extends object>(this: void, key: string, defaults: T): T;` - This mod's saved state for this game under key: the table saved there, or a copy of defaults the first time. Plain data and handles, saved with the game (see the storage rules in the reference); restored before `server` is called. One key, one shape: every call site names the key and its defaults, so two cannot disagree about a slot's type.
- `readonly loaded: boolean;` - Whether storage came from a save (or a reload) rather than starting empty.
- `readonly registry: GameRegistries;` - The behaviour registries of this game.
- `readonly difficulty: Difficulty;`
- `readonly expansion: boolean;`
- `readonly name: string;` - The game's name (empty in single player).
- `readonly seed: integer;` - The map seed.
- `readonly frame: integer;` - The engine's frame counter (25 frames a second).
- `players(this: void): LuaIterable<Player>;` - The players in the game.
- `level(this: void, id: LevelId): Level | undefined;` - The level when it exists in this game now (never makes one).
- `findUnit(this: void, type: UnitType, id: integer): AnyUnit | undefined;` - A unit by type and id, when it is valid.
- `unitsNear(this: void, at: Subtile, radius: number, type?: UnitType): LuaIterable<AnyUnit>;` - Units within radius subtiles of a point, optionally of one type.
- `spawnMonster(this: void, id: MonsterId, at: Subtile | Unit, options?: SpawnOptions): Monster | undefined;` - Spawn a monster at the free spot nearest a point or a unit, in an active room. Undefined when there is no active room there or no free spot.
- `message(this: void, text: string): void;` - A system line to every player in the game.
- `on<K extends keyof ServerEvents>(this: void, event: K, handler: ((this: void, e: ServerEvents[K]) => void) | undefined): void;` - Subscribe to an event; undefined unsubscribes. One handler per event per mod.
- `startScript(this: void, body: (this: void) => Script<void>, owner?: Handle): ScriptTask;` - Start a script in this game, owned by this mod and, when given, by owner: it is dropped once the owner's object is gone. It first runs on the next tick; every tick resumes the scripts that are due in the order they started.
- `waitEvent<K extends keyof ServerEvents>(this: void, event: K): Script<ServerEvents[K]>;` - Wait for an event of this game inside one of its scripts. The outcome is the payload.
- `channel<R extends Messages, E extends Messages>(this: void, declaration: ChannelDeclaration<R, E>): ServerChannel<R, E>;` - Open a channel of this mod for this game.
- `persist<T extends object>(this: void, owner: Handle, defaults: T): T;` - The persisted state of owner in this game, created from a copy of defaults the first time; kept in storage and dropped once the owner's object is gone.
- `hasPersisted(this: void, owner: Handle): boolean;` - Whether owner has persisted state in this game.

Wait ticks (default 1) inside a script. The outcome is the tick it resumes on.

Wait until pred holds, checking it now and then once a tick, for at most timeoutTicks ticks.
Outcome.Done when it held, Outcome.Timeout when the time ran out first.

### `function guard<T>(check: (this: void) => boolean, body: Script<T>): Script<T | Outcome>;`

Run body as a step of this script while check holds. check is called before each step of the
body: before it starts and before every resume after it waited. While it holds the body runs as
if it were called with `yield*` (what the script is resumed with reaches the body, what the body
waits for the script waits for); once it does not, the body is dropped where it waits, never
resumed again, and the outcome is Outcome.Interrupted. Otherwise the outcome is the body's.

A body waits as a whole: a `wait(100)` or an action the engine runs is not cut short, and an
action the body started is left to the engine as it runs it. Errors in check or body propagate.
Guards nest. Outside a script, in a coroutine of the mod's own (a test driving a Script), the
body's waits reach whoever resumes it. `yield* guard(() => target.valid && !target.dead, chase(monster, target))`: the
build hands the body over unstarted. In Lua the body is a function that runs it:
`guard(check, function() return chase(monster, target) end)`.

## storage

A mod's `game.storage` is saved with the game. It holds booleans, numbers, strings, tables without a
metatable, and handles; keys are strings, numbers or booleans. Shared tables and cycles are kept.
Functions, coroutines and other userdata are refused with the path of the value in the error.
